From the very basics (variables, loops, methods) all the way to more advanced concepts (generics, streams, concurrency, Spring… eventually), this repository is my public, step-by-step record of learning modern Java.

### What you’ll find here

- Clear, beginner-friendly explanations and code examples  
- Honest mistakes (and how I fixed them)  
- Small projects and mini-exercises that grow in complexity  
- Real “wait… *that’s* how it works?!” moments

No gatekeeping, no rush - just consistent, honest learning.
